SITO COMPLETO PER GITHUB PAGES

1. Estrai lo ZIP.
2. Carica nella RADICE del repository il file index.html e la cartella assets (non la cartella esterna).
3. In Settings > Pages usa Deploy from a branch, main, /(root).
4. Non serve installare nulla.

Contiene 91 fotografie JPEG in 11 categorie. Le pagine informative hanno foto accanto ai testi; le realizzazioni hanno gallerie a scorrimento ogni 5 secondi.

ATTENZIONE: per PORTE INTERNE esistono 12 foto ma sono state fornite solo 11 didascalie. La didascalia della dodicesima è provvisoria e segnalata esplicitamente nel sito.

Il sito precedente non viene modificato: questo ZIP serve per sostituire i file del repository GitHub Pages.
